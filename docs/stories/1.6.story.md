# Story 1.6 — Legendas Animadas Estilo Viral

**Status:** Draft
**Epic:** 1 — Infraestrutura
**Agente:** @dev (Dex)
**Prioridade:** Alta
**Depende de:** Story 1.5

---

## User Story
Como editor, quero que os clipes saiam com legendas animadas no estilo viral (palavra por palavra destacada, fonte grande), para que o conteúdo seja acessível e tenha mais engajamento.

---

## Contexto
Usa FFmpeg com formato `.ASS` (Advanced SubStation Alpha) para renderizar legendas diretamente no vídeo. Estilo karaokê: palavra atual em amarelo/branco com sombra, restante em branco semi-transparente. Sincronização word-level a partir do `transcript.json`.

---

## Critérios de Aceite

- [ ] Após `cut`, Celery aplica legendas em todos os clipes
- [ ] Status atualiza: `cut → captioning → captioned`
- [ ] Legendas sincronizadas palavra por palavra (não linha por linha)
- [ ] Palavra atual destacada em cor diferente (padrão: amarelo #FFD700)
- [ ] Fonte: Arial Bold, tamanho 72px no formato vertical
- [ ] Sombra preta atrás de todas as palavras para legibilidade
- [ ] Máximo 4 palavras por linha
- [ ] Legendas posicionadas na parte inferior (20% do fundo)
- [ ] Clipes com legenda salvos como `{filename}_captioned.mp4`
- [ ] Configuração de cor editável via variável de ambiente

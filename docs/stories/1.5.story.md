# Story 1.5 — Corte Automático de Clipes com FFmpeg

**Status:** Draft

---

## User Story
Como editor, quero que os momentos virais identificados sejam cortados automaticamente em clipes prontos, em formato vertical (9:16) e horizontal (16:9), para que estejam prontos para publicação.

---

## Contexto
Usa FFmpeg para cortar os clipes com base nos timestamps do `viral_moments.json`. Exporta dois formatos: vertical para Reels/TikTok/Shorts e horizontal para YouTube. Aplica padding/blur nas bordas do formato vertical quando necessário.

---

## Critérios de Aceite

- [ ] Após `analyzed`, Celery inicia corte automaticamente
- [ ] Status atualiza: `analyzed → cutting → cut`
- [ ] Para cada momento viral, gera 2 clipes: `{job_id}_clip{n}_vertical.mp4` e `{job_id}_clip{n}_horizontal.mp4`
- [ ] Formato vertical: 1080x1920 (9:16) com blur nas bordas
- [ ] Formato horizontal: 1920x1080 (16:9) direto
- [ ] Clipes salvos em `data/clips/{job_id}/`
- [ ] Clipes registrados na tabela `clips` do banco de dados
- [ ] Início do clipe: 2s antes do timestamp de início (contexto)
- [ ] Fim do clipe: 1s após o timestamp de fim
- [ ] Qualidade de saída: CRF 18, codec H.264

---

## Definição de Pronto (DoD)
- Clipes gerados em ambos os formatos sem erros
- Duração dos clipes corresponde aos timestamps + padding
- Formato vertical com blur correto aplicado
- Registros criados no banco para cada clipe
- Testes passam

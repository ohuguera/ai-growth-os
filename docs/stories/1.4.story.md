# Story 1.4 — Detecção de Momentos Virais com IA (iGaming)

**Status:** Draft

**Depende de:** Story 1.3

---

## User Story
Como editor, quero que a IA analise a transcrição e identifique automaticamente os melhores momentos virais de iGaming, para que eu não precise assistir horas de live para encontrá-los.

---

## Contexto
Usa Ollama com `llama3.1:8b` rodando localmente. Recebe a transcrição segmentada e retorna uma lista de timestamps com score viral e motivo da seleção. Prompt especializado em conteúdo de crash, roleta e iGaming.

---

## Critérios de Aceite

- [ ] Após `transcribed`, Celery inicia análise automaticamente
- [ ] Status atualiza: `transcribed → analyzing → analyzed`
- [ ] Arquivo `viral_moments.json` gerado em `data/downloads/{job_id}/`
- [ ] Estrutura do JSON: `[{ "start": 120.5, "end": 180.0, "score": 95, "reason": "Grande ganho no crash + reação extrema", "type": "big_win" }]`
- [ ] Mínimo de 5 e máximo de 15 momentos detectados por vídeo de 1h
- [ ] Score viral de 0-100 atribuído a cada momento
- [ ] Tipos reconhecidos: `big_win`, `dramatic_turn`, `viral_phrase`, `community_interaction`, `funny_moment`
- [ ] Tempo de análise: ≤ 3min para transcrição de 1h de vídeo

---

## Prompt Base para o LLM

```
Você é um especialista em conteúdo viral de iGaming.
Analise esta transcrição de uma live de crash/roleta e identifique os momentos mais virais.

Critérios de score:
- 90-100: Ganho enorme + reação extrema do streamer
- 80-89: Virada dramática (quase perdeu → ganhou)
- 70-79: Frase marcante que vai explodir no Twitter/TikTok
- 60-69: Momento engraçado ou inesperado
- 50-59: Interação intensa com lead da comunidade

Para cada momento, retorne JSON com: start, end, score, reason, type.
Retorne apenas o JSON, sem texto adicional.
```

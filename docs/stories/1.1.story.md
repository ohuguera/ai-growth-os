## User Story
Como desenvolvedor, quero ter o ambiente do projeto configurado com todas as dependências instaladas, para que as demais features possam ser implementadas sem atrito.

---

## Contexto
Esta é a story fundacional. Nenhuma outra story pode começar sem ela. Configura o monorepo com FastAPI (backend) + Next.js (frontend) + Docker Compose + Redis + SQLite.

---

## Critérios de Aceite

- [ ] Repositório `hr-troop-ux` inicializado com estrutura de pastas definida na arquitetura
- [ ] `docker-compose.yml` sobe todos os serviços com `docker compose up`
- [ ] FastAPI rodando em `localhost:8000` com endpoint `/health` retornando `{"status": "ok"}`
- [ ] Next.js rodando em `localhost:3000` com página inicial
- [ ] Redis rodando e conectado ao Celery worker
- [ ] SQLite inicializado com schema base (tabelas: `jobs`, `clips`)
- [ ] `yt-dlp`, `ffmpeg`, `whisper` instalados e acessíveis no container Python
- [ ] Ollama instalado localmente com modelo `llama3.1:8b` disponível
- [ ] `README.md` com instruções de setup em português

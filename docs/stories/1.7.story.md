# Story 1.7 — Entrega no Google Drive + Notificação WhatsApp

**Status:** Draft
**Epic:** 1 — Infraestrutura
**Agente:** @dev (Dex)
**Prioridade:** Alta
**Depende de:** Story 1.6

---

## User Story
Como editor, quero que os clipes prontos sejam enviados automaticamente para o Google Drive e receber uma notificação no WhatsApp, para que eu possa revisar sem precisar checar o sistema manualmente.

---

## Contexto
Usa Google Drive API v3 com OAuth2 para upload. Cria estrutura de pastas automática. Usa WhatsApp Business API (ou Evolution API auto-hospedada) para enviar mensagem de notificação com link direto dos clipes.

---

## Critérios de Aceite

- [ ] Após `captioned`, Celery inicia upload automaticamente
- [ ] Status atualiza: `captioned → uploading → completed`
- [ ] Clipes enviados para pasta: `HR-Troop-UX/{YYYY-MM-DD}/{streamer_name}/`
- [ ] Pasta criada automaticamente se não existir
- [ ] Apenas os clipes `_captioned.mp4` são enviados (não os intermediários)
- [ ] Link do Google Drive salvo no banco para cada clipe
- [ ] Notificação WhatsApp enviada ao concluir com: nome do streamer, quantidade de clipes, link da pasta
- [ ] Falha no upload não trava o job (retry automático 3x)
- [ ] `GET /api/jobs/{id}` inclui links do Drive nos clipes

---

## Tarefas Técnicas

- [ ] Criar `api/services/drive.py` com Google Drive API v3
- [ ] Configurar OAuth2 com `credentials.json` e `token.json`
- [ ] Criar `api/services/notifier.py` com cliente WhatsApp
- [ ] Criar `worker/tasks/deliver_task.py` como Celery task
- [ ] Implementar criação de pasta hierárquica no Drive
- [ ] Implementar retry com exponential backoff para falhas de upload
- [ ] Adicionar campo `drive_url` nos clipes do banco
- [ ] Criar `.env.example` com variáveis necessárias
- [ ] Criar testes mockados: `api/tests/test_delivery.py`

---

## Variáveis de Ambiente Necessárias
```
GOOGLE_DRIVE_FOLDER_ID=...      # ID da pasta raiz no Drive
WHATSAPP_API_URL=...            # URL da Evolution API
WHATSAPP_TOKEN=...              # Token de autenticação
WHATSAPP_PHONE=...              # Número para notificações
```

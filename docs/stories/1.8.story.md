# Story 1.8 — Painel Web de Demandas

**Status:** Draft
**Epic:** 1 — Infraestrutura
**Agente:** @dev (Dex)
**Prioridade:** Média
**Depende de:** Story 1.2 (API de jobs)

---

## User Story
Como editor da equipe, quero um painel web simples para enviar demandas de vídeo e acompanhar o status em tempo real, para que eu não precise usar terminal ou API diretamente.

---

## Contexto
Interface Next.js 14 com Tailwind. Três telas principais: enviar demanda, acompanhar status, revisar clipes prontos. Atualização de status em tempo real via polling (a cada 5s). Design simples e funcional — não precisa ser bonito, precisa ser útil.

---

## Critérios de Aceite

- [ ] Página `/submit`: formulário com campos: URL do vídeo, nome do streamer, observações
- [ ] Validação do formulário: URL obrigatória e válida, nome obrigatório
- [ ] Após envio, redireciona para `/jobs/{id}` com status em tempo real
- [ ] Página `/dashboard`: lista todos os jobs com status, data e streamer
- [ ] Status exibido visualmente: badge colorido (🟡 Processando / ✅ Pronto / ❌ Erro)
- [ ] Página `/jobs/{id}`: detalhes do job + lista de clipes quando prontos
- [ ] Clipes exibidos com: thumbnail, duração, score viral, link do Drive
- [ ] Polling automático a cada 5s enquanto job estiver em processamento
- [ ] Layout responsivo (funciona em tela 1080p)
- [ ] Sem autenticação na Fase 1 (acesso local apenas)

## Definição de Pronto (DoD)
- É possível enviar um vídeo pelo painel e acompanhar todo o pipeline
- Status atualiza automaticamente sem recarregar a página
- Clipes aparecem com links do Drive quando processamento termina
- Funciona no Chrome/Edge modernos

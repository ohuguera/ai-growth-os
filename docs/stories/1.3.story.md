# Story 1.3 — Transcrição Automática com Whisper (GPU)

**Status:** Draft
**Epic:** 1 — Infraestrutura
**Agente:** @dev (Dex)
**Prioridade:** Alta
**Depende de:** Story 1.2

---

## User Story
Como editor, quero que o vídeo seja transcrito automaticamente após o download, para que a IA possa analisar o conteúdo e identificar os melhores momentos.

---

## Contexto
Usa `faster-whisper` (versão otimizada para GPU) com modelo `large-v3`. Gera arquivo `.SRT` com timestamps precisos por palavra. Otimizado para português brasileiro e conteúdo de iGaming (vocabulário: crash, roleta, multiplicador, etc).

---

## Critérios de Aceite

- [ ] Após status `downloaded`, Celery inicia transcrição automaticamente
- [ ] Status atualiza: `downloaded → transcribing → transcribed`
- [ ] Arquivo `transcript.srt` gerado em `data/downloads/{job_id}/`
- [ ] Arquivo `transcript.json` gerado com estrutura: `[{ "start": 0.0, "end": 2.5, "text": "...", "words": [...] }]`
- [ ] Transcrição em português brasileiro com precisão ≥ 90%
- [ ] Tempo de processamento: 1h de vídeo transcrito em ≤ 10min (com GPU)
- [ ] Fallback para CPU se GPU não disponível (com aviso de performance)
- [ ] Logs mostram progresso: percentual transcrito

---

## Tarefas Técnicas

- [ ] Criar `api/pipeline/transcriber.py` com wrapper do `faster-whisper`
- [ ] Criar `worker/tasks/transcribe_task.py` como Celery task
- [ ] Configurar modelo `large-v3` com `device="cuda"` e `compute_type="float16"`
- [ ] Implementar detecção automática de GPU (CUDA disponível?)
- [ ] Gerar `.SRT` formatado corretamente com timestamps por segmento
- [ ] Gerar `.JSON` com timestamps por palavra (para legendas animadas)
- [ ] Adicionar vocabulário customizado de iGaming (crash, roleta, etc)
- [ ] Criar testes: `api/tests/test_transcription.py`

---

## Definição de Pronto (DoD)
- Transcrição de vídeo de 10min conclui em menos de 2min na GPU
- Arquivo `.SRT` legível e com timestamps corretos
- Arquivo `.JSON` com estrutura de palavras para uso no legendador
